# Shoot_The_Drone


# [개인 프로젝트 채점 기준]
총점: 100점

1. 프로젝트 계획서 (Project Proposal) - 15점

●      개요 및 목표 명확성 (5점):

○      게임의 컨셉, 목표, 플레이 방식이 명확하고 이해하기 쉽게 제시되었는가?

○      프로젝트의 동기가 설득력 있게 설명되었는가?

●      내용 구체성 및 충실도 (10점):

○      게임 규칙, 주요 기능, 구성 요소 등이 구체적으로 기술되었는가?

○      사용할 기술(라이브러리 등)과 개발 계획이 현실적으로 제시되었는가?

○      예상되는 어려움을 미리 파악하고 해결 방안을 고민한 흔적이 보이는가?

2. 구현 결과물 (Implemented Game) - 55점

●      핵심 기능 구현 및 동작 (25점):

○      게임이 오류 없이 실행되고 플레이 가능한 상태인가?

○      계획서에 제시된 게임의 핵심 규칙 및 플레이 방식이 제대로 구현되었는가?

○      플레이어 조작, 게임 진행, 종료 조건 등 필수 기능이 정상 동작하는가?

●      코드 품질 (20점):

○      코드의 가독성: 변수/함수 이름이 의미 있고, 주석이 필요한 곳에 적절히 달려있는가?

○      코드 구조: 코드가 논리적으로 잘 구성되어 있는가? (예: 함수 활용, 반복/조건문 적절 사용 등)

○      파이썬 문법 및 활용: 강의에서 배운 파이썬 문법 및 개념(자료구조, 함수 등)을 적절히 활용했는가?

○      (선택 사항: 수준에 따라) 기본적인 효율성 또는 오류 방어 코드가 적용되었는가?

●      기능 구현 충실도 (10점):

○      계획서에 제시된 주요 기능 및 추가 기능들이 얼마나 완성도 높게 구현되었는가?

○      (난이도 고려) 프로젝트의 범위와 학생의 수준에 맞는 적절한 난이도의 게임을 선택하고 구현했는가?

3. 결과 보고서 (Final Report) - 30점

●      내용의 충실성 및 정확성 (5점):

○      보고서의 모든 항목이 누락 없이 작성되었는가?

○      보고서 내용이 실제 구현 결과 및 개발 과정을 정확하게 반영하고 있는가?

●      개발 과정 및 어려움/해결 경험 서술 (10점):

○      프로젝트 개발 과정을 구체적으로 설명했는가?

○      개발 중 겪었던 어려움을 명확히 제시하고, 이를 해결하기 위해 어떤 시도를 했는지 구체적으로 서술했는가?

●      인공지능 도움 활용 내용 (5점):

○      인공지능 도구의 사용 여부 및 사용 목적/방법을 명확하게 기술했는가?

○      인공지능 활용을 통해 얻은 이점과 느낀 점(주의할 점 등)을 포함하여 작성했는가?

●      자기 평가 및 회고 (5점):

○      프로젝트 결과물과 개발 과정에 대해 스스로 객관적으로 평가했는가?

○      프로젝트를 통해 무엇을 배우고 느꼈는지 성찰적인 내용을 담고 있는가?

○      향후 개선/확장 계획에 대한 아이디어를 제시했는가?

●      보고서 구성 및 가독성 (5점):

○      보고서가 논리적인 흐름으로 구성되어 있고 이해하기 쉽게 작성되었는가?

○      오탈자나 문법 오류가 적고 전반적으로 정돈된 느낌을 주는가?

○      코드 제출 방식 등이 명확하게 안내되었는가?
